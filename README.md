# 🤖 Конструктор ИИ-ботов (Мастер-класс)

Готовое веб-приложение для проведения интерактивного детского мастер-класса по искусственному интеллекту на 25+ участников.

Дети создают собственных ИИ-персонажей (задают имя, эмодзи-аватарку, характер и системный промпт), обучают их фактам из базы знаний (текст или файлы `.txt`, `.pdf`, `.docx`), после чего общаются со своими ботами и ботами одноклассников в реальном времени со стримингом ответов по словам.

---

## 🚀 Архитектура и стек

- **Бэкенд**: Python 3.10+, FastAPI, Uvicorn, встроенный SQLite (`bots.db`), библиотека `openai` (AsyncOpenAI), `pypdf`, `python-docx`, `python-multipart`, `rank-bm25`.
- **Фронтенд**: один самодостаточный файл `index.html` со встроенным стильным CSS и чистым JavaScript (без React/Node.js, без сборки).
- **RAG (Поиск по базе знаний)**: Быстрый поиск релевантных фактов через BM25Okapi с токенизацией по словам без необходимости тяжелых эмбеддинг-моделей.
- **Локальная LLM**: встроенная поддержка `llama-server` с официальной квантованной моделью **Qwen 2.5 3B Instruct** (GGUF, ~1.9 ГБ).

## 💻 Быстрый запуск на Windows Server

### Шаг 1: Скачивание модели и llama-server (1 клик)
Дважды кликните по:
```cmd
download_model.bat
```
> Скрипт сам скачает официальный `llama-server.exe` для Windows и модель `qwen2.5-3b-instruct-q4_k_m.gguf` в папку `llm/`.

### Шаг 2: Запуск локальной LLM
Дважды кликните по:
```cmd
start_llm.bat
```
> Сервер OpenAI API модели запустится на `http://127.0.0.1:8000/v1`.

### Шаг 3: Запуск веб-сервера приложения
Дважды кликните по:
```cmd
start_web.bat
```
> Скрипт создаст виртуальное окружение `venv`, установит библиотеки из `requirements.txt` и запустит веб-интерфейс на порту `3000`.

### Шаг 4: Открытие порта в Брандмауэре Windows (для участников)
Чтобы 25 участников могли подключиться со своих ноутбуков или смартфонов по локальной сети Wi-Fi, запустите командную строку (CMD) от имени Администратора:
```cmd
netsh advfirewall firewall add rule name="AI-Bot-Constructor" dir=in action=allow protocol=TCP localport=3000
```
Узнайте IP-адрес сервера (`ipconfig`, например `192.168.1.100`), и участники смогут открыть в браузере:
```
http://192.168.1.100:3000
```

## 📡 API Эндпоинты

- `GET /` — Отдает веб-интерфейс `index.html`.
- `POST /api/bots` — Создание нового бота (`name`, `avatar`, `system_prompt`, `kb_text`, `kb_file`). Нарезка текста на чанки по ~400 символов с перекрытием 50 символов.
- `GET /api/bots` — Список всех созданных ботов участников с количеством чанков знаний.
- `GET /api/bots/{bot_id}` — Получение данных конкретного бота по ID.
- `POST /api/chat` — Чат с ботом со стримингом ответа (`StreamingResponse`, `text/plain`).
