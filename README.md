# КС54 • AI-Интегратор

Веб-приложение для проектирования, настройки и тестирования ИИ-ботов в локальной сети (20+ одновременных подключений). Состоит из серверной части на FastAPI (`main.py`), клиентского интерфейса в одном файле (`index.html`), базы данных SQLite (`bots.db`) и внешнего сервера инференса `llama-server` (OpenAI-совместимый HTTP API).

## Архитектура системы

Запрос пользователя проходит три узла:

1. **Браузер (`index.html`)**: хранит схему нод, историю диалогов, настройки рабочего места и локальный кэш прогресса в `localStorage`. Взаимодействует с сервером по HTTP (`3000`).
2. **Веб-сервер (`main.py`, Uvicorn, порт `3000`)**: раздаёт интерфейс и статику (`/static`), управляет таблицами SQLite (`bots`, `knowledge_chunks`, `user_task_progress`), разбирает загруженные документы (`.txt`, `.pdf`, `.docx`), выполняет поиск релевантных фрагментов через `BM25Okapi` и проксирует потоковую генерацию от LLM к клиенту.
3. **Сервер модели (`llama-server`, порт `8000`)**: обслуживает модель `qwen2.5-3b-instruct-q4_k_m.gguf` по API `/v1` (`AsyncOpenAI` на клиенте пула `httpx` с лимитами `max_connections=120`, `max_keepalive_connections=50`, таймаут `180.0` с, подключение `10.0` с).

## Установка и запуск

### Linux

```bash
# 1. Скачать бинарник llama-server и модель qwen2.5-3b-instruct-q4_k_m.gguf в каталог llm/
./download_model.sh

# 2. Запустить сервер модели в первом терминале (порт 8000)
```

Примечание: в `start_linux.sh` выводится текстовая строка с портом `8080`, однако фактически `main.py` по умолчанию подключается к `http://127.0.0.1:8000/v1`, на который и запускается `start_llm.sh`.

```bash
git pull origin main
```

Если обновлялся `main.py`, необходимо перезапустить процесс Uvicorn. Если обновлялся только `index.html`, перезапуск не требуется — достаточно обновить страницу в браузере (`Ctrl + F5`). При изменении `requirements.txt` выполните внутри `venv`:

```bash
pip install -r requirements.txt
```

## Обработка файлов и поиск RAG (BM25)

1. **Извлечение текста (`extract_text_from_file`)**:
   - Максимальный размер загружаемого файла: `1 МБ` (`1024 * 1024` байт). При превышении возвращается `400`.
   - Поддерживаемые расширения:
     - `.txt` — декодирование в порядке `utf-8` → `cp1251` → `latin-1`.
     - `.pdf` — построчное извлечение текста по всем страницам через `pypdf.PdfReader`.
     - `.docx` — чтение непустых абзацев через `python-docx`.
2. **Разбиение на фрагменты (`chunk_text`)**:
   - Нормализация пробельных символов (`re.sub(r"\s+", " ", text).strip()`).
   - Размер чанка: `chunk_size = 400` символов, перекрытие `overlap = 50` символов.
3. **Поиск релевантных фрагментов (`/api/chat` и `/api/test-draft`)**:
   - Все чанки и текст вопроса приводятся к нижнему регистру и токенизируются (`re.findall(r"\w+", text.lower())`).
   - Ранжирование выполняется через `BM25Okapi`.
   - Выбираются до **3** чанков с оценкой `score > 0`. Если токены вопроса пустые или ни один чанк не набрал `score > 0`, передаются первые **2** чанка (`docs[:2]`).
   - Найденные фрагменты подставляются в конец системного сообщения перед отправкой в LLM.

## HTTP API

### `GET /`
Возвращает файл `index.html` (`text/html`). Статические ресурсы доступны по префиксу `/static`.

### `POST /api/bots`
Создаёт нового бота. Принимает `multipart/form-data`:
- `name` (`str`, обязательно)
- `avatar` (`str`, обязательно; пустое значение заменяется на `🤖`)
- `system_prompt` (`str`, обязательно)
- `kb_text` (`str`, опционально)
- `kb_file` (`UploadFile`, опционально)
- `temperature` (`float`, по умолчанию `0.7`)
- `max_tokens` (`int`, по умолчанию `350`)
- `user_id` (`str`, по умолчанию `"anon"`)

Ответ (`200 OK`): объект бота с присвоенным 6-символьным `id`, количеством чанков `chunks_count` и `created_at`.

### `GET /api/bots`
Возвращает список всех ботов, отсортированный по `created_at DESC`, с полями `id`, `name`, `avatar`, `system_prompt`, `temperature`, `max_tokens`, `created_at`, `user_id` (пустое значение маппится в `"anon"`), `chunks_count`.

### `GET /api/bots/{bot_id}`
Возвращает данные одного бота по `id` или `404`, если бот не найден.

### `PUT /api/bots/{bot_id}`
Обновляет существующего пользовательского бота (`multipart/form-data` с теми же полями, что и `POST /api/bots`).
- Если бот не найден — `404`.
- Если `bot_id` относится к `STARTER_BOT_IDS` или `user_id == 'system'` — `403`.
- Если передан `kb_text` или `kb_file`, старые чанки в `knowledge_chunks` заменяются новыми.

### `DELETE /api/bots/{bot_id}`
Удаляет пользовательского бота и каскадно его записи в `knowledge_chunks`.
- Если бот не найден — `404`.
- Если `bot_id` относится к `STARTER_BOT_IDS` или `user_id == 'system'` — `403`.

### `POST /api/chat`
Выполняет потоковый запрос к LLM для сохранённого бота. Тело запроса (`application/json`):
```json
{
  "bot_id": "abc123",
  "message": "Текст вопроса",
  "history": [
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."}
  ]
}
```
В контекст передаётся системный промпт (с фрагментами RAG при наличии), последние **6** сообщений из `history` и текущее сообщение. Ответ отдаётся как `StreamingResponse` (`text/plain`).

### `POST /api/test-draft`
Потоковое тестирование несохранённой схемы из ноды «Терминал Бота» и модуля AI-экзамена. Тело запроса (`application/json`):
- `message` (`str`)
- `system_prompt` (`str`)
- `temperature` (`float`, по умолчанию `0.7`)
- `max_tokens` (`int`, по умолчанию `160`)
- `kb_text` (`str | null`)
- `history` (`list[dict] | null`, берутся последние 6 сообщений)

### `GET /api/progress/{user_id}` и `PUT /api/progress/{user_id}`
- `GET` возвращает сохранённый JSON прогресса пользователя (`{"user_id": "...", "progress": {...} | null, "updated_at": "..."}`).
- `PUT` принимает `{"progress": {...}}` и сохраняет/обновляет запись в таблице `user_task_progress`.

## Веб-интерфейс и визуальный редактор

Интерфейс разделён на две основные вкладки (`Схема нод` и `Чат и Галерея`) и выдвижную правую панель (`База проекта`). По умолчанию активна светлая тема (`data-theme="light"`), переключение на тёмную тему сохраняется в `localStorage` (`bot_theme`).

### Холст и навигация
- Перемещение поля: удержание левой кнопки мыши на пустом фоне.
- Масштабирование: колёсико мыши или кнопки в правом нижнем углу (`−`, `+`, `⟲`). Прокрутка внутри текстовых полей, меню и экрана экспресс-чата перехватывается и не масштабирует холст.
- Перемещение блоков: удержание левой кнопки мыши за заголовок ноды.
- Соединение портов (2 способа):
  1. Перетащить курсор от кружка выхода (`out`) к входному кружку (`in`) того же типа и цвета.
  2. Кликнуть по одному порту (подсветятся совместимые порты), затем кликнуть по целевому порту.
- Отсоединение провода: клик левой кнопкой мыши по линии провода.
- Автосохранение холста: все ноды, их координаты, значения и связи автоматически сохраняются в `localStorage` (`bot_workflow_canvas`).

### Библиотека из 11 модулей

| Тип (`data-type`) | Название в меню | Вход / Выход | Назначение и параметры |
|---|---|---|---|
| `char` | Персонаж | Выход `char` → `brain` | Имя бота (`.node-val-name`) и выбор аватара-эмодзи |
| `prompt` | Инструкция (Промпт) | Выход `prompt` → `brain` | Системный промпт и 4 быстрых шаблона роли |
| `brain` | Мозг Бота (Ядро) | Входы 8 типов → Выход `brain` → `assembler` | Концентратор конфигурации личности с индикаторами подключения (`ПОДКЛЮЧЕНО` / `ОЖИДАНИЕ` / `ОПЦИЯ`) |
| `assembler` | Терминал Бота | Входы `brain`, `kb` | Финальная нода сборки, встроенный «Экспресс-чат» (`/api/test-draft`) и кнопка запуска в галерею |
| `params` | Креативность и Длина | Выход `params` → `brain` | Ползунок `Temp` (`0.1–1.3`) и переключатель длины (`140` / `350` токенов) |
| `format` | Формат Данных | Выход `format` → `brain` | Режимы вывода: `markdown`, `table`, `json`, `code`, `tldr` (добавляют строгую инструкцию в промпт) |
| `fewshot` | Few-Shot (Примеры) | Выход `fewshot` → `brain` | 2 пары «Вопрос → Эталонный ответ» и пресеты обучения |
| `guard` | Рамки и Фильтры | Выход `guard` → `brain` | Языковой лок (`any`/`ru`/`en`), «Метод Сократа», «Формулы в LaTeX», «Анти-галлюцинация» |
| `rules` | Стиль и Правила | Выход `rules` → `brain` | Выбор тона общения и 4 флага правил ответа |
| `quick` | Приветствие и Кнопки | Выход `quick` → `brain` | Первая реплика при открытии чата и до 3 кнопок-подсказок (хранятся локально в `bot_ui_{id}`) |
| `kb` | База знаний (RAG) | Выход `kb` → `assembler` | Текстовые факты и/или загрузка файла `.txt`, `.pdf`, `.docx` до 1 МБ |

### Управление ботами, редактирование и изоляция сессий
- **Рабочее место**: при первом входе браузер генерирует `ks54_user_id` (`user_...`) и имя ПК (`ПК-01`..`ПК-30`). Имя можно изменить, а сессию — сбросить через кнопку профиля в шапке.
- **Фильтры в Галерее**:
  - `Мои боты` — только боты с `user_id`, равным `ks54_user_id` текущего пользователя. На каждой карточке доступны редактирование (`⚙️`) и удаление (`✕`). При удалении последнего бота вкладка остаётся пустой с кнопками перехода к сборке или шаблонам.
  - `КС54` — 7 предустановленных системных образцов (`user_id === 'system'`). Удалить их нельзя; нажатие `📋` копирует схему на холст пользователя как новый черновик (`editingBotId = null`).
  - `Все` — все боты на сервере; редактирование чужих и системных ботов всегда создаёт копию под профилем текущего пользователя, не затрагивая оригинал. Удалять можно только собственных ботов.
- **Обновление vs создание нового**: при редактировании собственного бота в верхней части холста отображается панель с кнопкой «Собрать нового с нуля» (`createNewBotOnCanvas()`), сбрасывающей `editingBotId`.
- **Чат**: потоковый вывод с рендерингом Markdown (заголовки, списки, таблицы, цитаты, инлайн-блоки кода и блоки кода с подсветкой заголовка), выделением текста, универсальным копированием (`navigator.clipboard` с фоллбэком на `document.execCommand('copy')` для работы по HTTP без TLS) и умным скроллом (автопрокрутка отключается при пролистывании вверх и появляется кнопка `↓ Вниз`).

## Система заданий и сохранения прогресса

1. **Интерактивный тур (`🎓 Обучение`)**: пошаговый 12-шаговый тур по интерфейсу с подсветкой элементов интерфейса (`TOUR_STEPS`). Запускается автоматически при первом визите или вручную кнопкой в шапке.
2. **Правая панель (`📖 База проекта`)**:
   - **О проекте** — базовая концепция AI-интегратора и тайминг занятия.
   - **Инструкция** — текстовый справочник по навигации, проводке, 11 модулям и частым ошибкам.
   - **6 блоков** — структура системного промпта (роль, задача, тон, RAG, границы, формат).
   - **Задания**:
     - Уровень 1 (новичок), Уровень 2 (RAG и температура), Уровень 3 (Guardrails и Few-Shot) с пошаговыми инструкциями и автоматической проверкой графа нод (`verifyPracticeLevel`).
     - Самостоятельный экзамен (3 варианта ТЗ: «Орион-54», «Приёмная КС54», «Сократ-Ревью») с проверкой архитектуры схемы (`verifyExamSchema`) и автоматическим прогоном тестовых запросов и провокаций через `/api/test-draft` (`runExamAITest`).

3. **Автосохранение прогресса**: результаты проверок всех уровней, ответы AI-экзамена, отмеченные пункты чек-листа и снимки схем нод для каждого задания сохраняются в `localStorage` (`ks54_task_progress_{user_id}`) и синхронизируются с сервером (`PUT /api/progress/{user_id}`). ## Диагностика неисправностей

- **При тестировании или в чате выводится `[Ошибка соединения: ...]`**
  Убедитесь, что `llama-server` запущен и отвечает на `http://127.0.0.1:8000/v1/models` (либо по адресу из `LLM_BASE_URL`).
- **Порт `3000` недоступен с других ПК в локальной сети**
  Проверьте правила брандмауэра на сервере (Windows: правило для TCP-порта `3000` и профиль сети «Частная сеть»; Linux: `ufw`/`iptables`).
- **Бот не использует данные из «Базы знаний (RAG)»**
  Проверьте, что выход ноды «База знаний» подключён проводом к ноде «Терминал Бота» (а не к «Мозгу Бота»), а в ноде «Креативность и Длина» выставлена температура `0.1–0.4`.
- **После правки `index.html` в браузере видна старая версия**
  Выполните жёсткое обновление страницы в браузере (`Ctrl + F5` или `Ctrl + Shift + R`).
