# 🤖 Конструктор ИИ-ботов (Мастер-класс)

Готовое веб-приложение для проведения интерактивного детского мастер-класса по искусственному интеллекту на 25+ участников.

Дети создают собственных ИИ-персонажей (задают имя, эмодзи-аватарку, характер и системный промпт), загружают базу знаний (текст или файлы `.txt`, `.pdf`, `.docx`), после чего общаются со своими ботами и ботами одноклассников в реальном времени со стримингом ответов.

---

## 🚀 Архитектура и стек

- **Бэкенд**: Python 3.10+, FastAPI, Uvicorn, встроенный SQLite (`bots.db`), библиотека `openai` (AsyncOpenAI), `pypdf`, `python-docx`, `python-multipart`, `rank-bm25`.
- **Фронтенд**: один самодостаточный файл `index.html` со встроенным стильным CSS и чистым JavaScript (без React/Node.js, без сборки).
- **RAG (Поиск по базе знаний)**: Быстрый поиск релевантных фактов через BM25Okapi с токенизацией по словам без необходимости тяжелых эмбеддинг-моделей.
- **LLM-бэкенд**: локальный сервер llama-server (по умолчанию `http://127.0.0.1:8080/v1`), модель Qwen 2.5 3B.

## 💻 Быстрый запуск на Windows Server

### 1. Предварительные требования
1. Установите [Python 3.10+](https://www.python.org/downloads/windows/) (обязательно отметьте галочку **«Add Python to PATH»** при установке).
2. Запустите `llama-server` с моделью (например, Qwen 2.5 3B) на порту 8080:
   ```cmd
   llama-server.exe -m qwen2.5-3b-instruct-q4_k_m.gguf --port 8080 -c 4096
   ```

### 2. Запуск приложения в один клик
Просто дважды кликните по файлу:
```cmd
start_web.bat
```

> **Что сделает скрипт автоматически:**
> - Создаст изолированное виртуальное окружение `venv`;
> - Установит все необходимые библиотеки из `requirements.txt`;
> - Запустит веб-сервер на `http://0.0.0.0:3000`.

### 3. Открытие порта в Брандмауэре Windows (для участников в локальной сети)
Чтобы все 25 участников могли зайти со своих ноутбуков или планшетов по локальной сети Wi-Fi, откройте командную строку (CMD) от имени Администратора и выполните:
```cmd
netsh advfirewall firewall add rule name="AI-Bot-Constructor" dir=in action=allow protocol=TCP localport=3000
```
Узнайте локальный IP-адрес сервера (команда `ipconfig`, например `192.168.1.100`), и участники смогут открыть в браузере:
```
http://192.168.1.100:3000
```

## ⚙️ Переменные окружения (Опционально)

При необходимости можно изменить параметры через переменные окружения:

| Переменная | Значение по умолчанию | Описание |
|---|---|---|
| `LLM_BASE_URL` | `http://127.0.0.1:8080/v1` | Адрес OpenAI-совместимого API локальной модели |
| `DB_PATH` | `bots.db` | Путь к файлу базы данных SQLite |

Пример запуска на нестандартном порту или адресе LLM:
```cmd
set LLM_BASE_URL=http://127.0.0.1:8080/v1
uvicorn main:app --host 0.0.0.0 --port 3000
```

## 📡 API Эндпоинты

- `GET /` — Отдает веб-интерфейс `index.html`.
- `POST /api/bots` — Создание нового бота (multipart: `name`, `avatar`, `system_prompt`, `kb_text`, `kb_file`). Нарезка текста на чанки по ~400 символов с перекрытием 50 символов.
- `GET /api/bots` — Список всех созданных ботов участников с количеством чанков знаний.
- `GET /api/bots/{bot_id}` — Получение данных конкретного бота по ID.
- `POST /api/chat` — Чат с ботом. Принимает `{ "bot_id": "...", "message": "...", "history": [...] }`, подбирает топ-3 релевантных факта через BM25, отправляет в LLM последние 6 сообщений истории и возвращает ответ потоком (`StreamingResponse`, `text/plain`).

## 💡 Советы для ведущего мастер-класса

1. **Шаблоны в 1 клик**: В интерфейсе предусмотрены готовые шаблоны («Пират-экскурсовод», «Школьный репетитор», «Квест-мастер», «Кот-учёный»), чтобы дети могли быстро понять принцип создания промптов.
2. **База знаний**: Подготовьте для ребят несколько небольших текстовых или Word-файлов (например, сказка, энциклопедия о динозаврах, космический путеводитель или правила настольной игры), чтобы они загрузили их в бота и протестировали точность ответов.
3. **Обмен ссылками**: Кнопка «Ссылка на бота» копирует ссылку вида `http://IP:3000/?bot=abc123`. Дети могут отправлять ссылки друг другу и общаться с ботами своих друзей!
