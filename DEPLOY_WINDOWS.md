# 🚀 Полное авторазвёртывание на Windows 10 Server (NVIDIA T1000 8GB • 20+ пользователей)

Инструкция по установке **КС54 • AI-Интегратор** с GitHub на чистый сервер **Windows 10** с видеокартой **NVIDIA T1000 (8 ГБ VRAM)** для одновременной работы **20–25+ студентов** в локальной сети.

---

## ⚡ Вариант 1: Установка одной командой с GitHub (Рекомендуется)

Этот способ работает даже на **абсолютно чистой Windows 10**, где ещё не установлены ни Git, ни Python, ни CUDA.

1. Нажмите `Win + X` → выберите **Windows PowerShell (администратор)** (или **Терминал (администратор)**).
2. Вставьте одну команду и нажмите `Enter`:

```powershell
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12; irm https://raw.githubusercontent.com/fourol/ai-bot-constructor/main/bootstrap_windows.ps1 | iex
```

### Что скрипт сделает сам:
1. Проверит и при необходимости установит **Git** (или скачает архив проекта напрямую с GitHub в `C:\ai-bot-constructor`).
2. Проверит и при необходимости автоматически установит **Python 3.11 (x64)**.
3. Создаст виртуальное окружение `venv` и установит все библиотеки (`fastapi`, `uvicorn`, `openai`, `httpx`, `rank-bm25`, `pypdf`, `python-docx`).
4. Определит видеокарту **NVIDIA T1000** и версию драйвера через `nvidia-smi`:
   - При драйвере **>= 550.54** — скачает официальную сборку **CUDA 12.4** (`llama-b12651-bin-win-cuda-12.4-x64.zip` + `cudart` DLL-библиотеки).
   - Если драйвер старее — предупредит и автоматически поставит GPU-сборку **Vulkan** (чтобы всё сразу работало на видеокарте).
5. Скачает квантованную модель **Qwen 2.5 3B Instruct (`qwen2.5-3b-instruct-q4_k_m.gguf`, ~2.0 ГБ)** с поддержкой докачки.
6. Откроет входящий TCP-порт **3000** в Брандмауэре Windows для доступа класса по локальной сети.
7. Создаст ярлык **«КС54 AI-Интегратор»** на Рабочем столе, выведет точный IP-адрес для учеников и предложит сразу запустить сервер.

## 🛠️ Вариант 2: Установка после ручного `git clone`

Если проект уже клонирован на сервер:

```cmd
git clone https://github.com/fourol/ai-bot-constructor.git C:\ai-bot-constructor
cd C:\ai-bot-constructor
```

Просто дважды кликните по файлу **`install_windows.bat`** (подтвердите запрос прав Администратора UAC).

---

## ▶️ Ежедневный запуск для класса (1 клик)

После установки для запуска достаточно дважды кликнуть по:
- ярлыку **«КС54 AI-Интегратор»** на Рабочем столе, или
- файлу **`start_all.bat`** в папке проекта.

Скрипт `start_all.bat`:
1. Запустит GPU-сервер нейросети (`start_llm.bat`) и дождётся полной загрузки модели в память T1000.
2. Запустит веб-сервер FastAPI + Uvicorn (`start_web.bat`) на `0.0.0.0:3000`.
3. Выведет в консоль готовые ссылки для студентов (например, `http://192.168.1.50:3000`) и откроет AI-интегратор в браузере.

> ⚠️ **Важно:** во время работы класса не закрывайте два открытых консольных окна (`KS54 LLM Server` и `KS54 Web Server`).

## ⚙️ Тюнинг под NVIDIA T1000 (8 ГБ) и 20+ пользователей

Настройки в `start_llm.bat`, `start_web.bat` и `main.py` специально рассчитаны под классную нагрузку:

| Компонент | Параметр | Назначение |
|---|---|---|
| **llama-server** | `-ngl 99` | Перенос 100% всех 36 слоёв Qwen 2.5 3B в видеопамять T1000 |
| **llama-server** | `-np 24` | **24 параллельных слота инференса** (Continuous Batching `-cb`) |
| **llama-server** | `-c 49152` | Общий KV-кэш на 49 152 токена (**по 2048 токенов контекста на каждого из 24 одновременно пишущих пользователей**) |
| **llama-server** | `-fa auto --threads-http 8` | Flash Attention на архитектуре Turing (T1000) + 8 HTTP-потоков |
| **Потребление VRAM** | ~4.3 ГБ из 8.0 ГБ | Остаётся ~3.7 ГБ запаса под Windows 10 и пиковые запросы |
| **FastAPI / SQLite** | `WAL` + `timeout=30s` + пул 120 сокетов | Без блокировок БД (`database is locked`) при одновременном создании ботов и стриминге |
| **Uvicorn** | `--backlog 2048 --timeout-keep-alive 65` | Стабильные длинные стриминговые соединения по Wi-Fi/LAN |

## 🌐 Подключение 20+ компьютеров учеников

1. Убедитесь, что сетевой профиль Windows 10 на сервере задан как **Частная сеть** (Private), а не Публичная.
2. На компьютере каждого ученика откройте браузер (Chrome/Edge/Firefox) и перейдите по адресу, который вывел `start_all.bat`:
   ```text
   http://<IP_СЕРВЕРА>:3000
   ```
3. Проверить статус правил Брандмауэра вручную (в CMD от Администратора):
   ```cmd
   netsh advfirewall firewall show rule name="KS54-AI-Bot-Constructor"
   ```

## 🔧 Устранение частых проблем

- **Ошибка `CUDA driver version is insufficient` при запуске `start_llm.bat`**:
  - Установите актуальный драйвер NVIDIA RTX / Quadro (ветка R550+ / 551.61+) для Windows 10 x64 с сайта `nvidia.com` **или** удалите `llm\ggml-cuda.dll` и перезапустите `install_windows.bat` (скрипт переключится на Vulkan GPU).
- **Модель запускается на CPU вместо T1000**:
  - Убедитесь, что в папке `llm\` лежат файлы `ggml-cuda.dll`, `cudart64_*.dll` и `cublas64_*.dll` (при установке через `install_windows.bat` / `deploy_windows.ps1` они скачиваются автоматически).
- **Ученики не могут открыть сайт по `http://<IP>:3000`**:
  - Проверьте, что сервер и ученики находятся в одной подсети/VLAN.
  - Проверьте правило Брандмауэра или временно проверьте сторонний антивирус (Kaspersky / Dr.Web часто блокируют порт 3000).
- **Как обновить проект с GitHub без потери базы ботов**:
  - Файл `bots.db` и папка `llm\` добавлены в `.gitignore`, поэтому обновление безопасно:
    ```cmd
    cd C:\ai-bot-constructor
    git pull origin main
    ```
